Rust · WebAssembly · Bitboards

PG-Chess

A chess engine written in Rust and compiled to WebAssembly: 64-bit bitboards, iterative deepening negamax with alpha-beta pruning and fail-soft bounds, a 32 MB transposition table, MVV-LVA ordering backed by killers and history, and a quiescence search at the leaves. The move generator is checked against the published perft counts, and the whole thing runs in a Web Worker so the board never freezes.
